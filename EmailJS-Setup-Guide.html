📧 EmailJS Setup Guide - SBRYMS Login System

⚠️ গুরুত্বপূর্ণ: এই গাইড অনুসরণ করে EmailJS সেটআপ করলে আপনার লগইন সিস্টেমে আসল ইমেইল যাবে।

📋 Step 1: EmailJS Account তৈরি করুন

1. EmailJS.com এ যান
2. "Sign Up" করে একাউন্ট তৈরি করুন
3. Email ভেরিফাই করুন

📧 Step 2: Email Service যোগ করুন

1. Dashboard এ যান
2. "Email Services" → "Add New Service"
3. Gmail বা আপনার ইমেইল প্রোভাইডার সিলেক্ট করুন
4. আপনার ইমেইল এবং পাসওয়ার্ড দিন
5. Service ID কপি করে রাখুন (যেমন: service_xxxxx)

📝 Step 3: Email Template তৈরি করুন

1. "Email Templates" → "Create New Template"
2. নিচের টেমপ্লেট কপি করে পেস্ট করুন:
Subject: {{subject}} Dear User, Your {{type}} verification code is: {{verification_code}} Please enter this code to complete the process. Best regards, SBRYMS Finance Team
3. Template ID কপি করে রাখুন (যেমন: template_xxxxx)

🔑 Step 4: Public Key নিন

1. "Account" → "General" এ যান
2. Public Key কপি করে রাখুন (যেমন: xxxxxxxx)

⚙️ Step 5: LOGIN.html আপডেট করুন

LOGIN.html ফাইলে এই লাইনগুলো খুঁজে আপনার তথ্য দিয়ে রিপ্লেস করুন:
// EmailJS ইনিশিয়ালাইজ emailjs.init("YOUR_PUBLIC_KEY"); // ← আপনার Public Key // EmailJS টেমপ্লেট আইডি await emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", templateParams); // ↑ YOUR_SERVICE_ID ↑ YOUR_TEMPLATE_ID

🧪 Step 6: টেস্ট করুন

1. LOGIN.html খুলুন
2. রেজিস্ট্রেশন বা পাসওয়ার্ড রিসেট করুন
3. আপনার ইমেইলে কোড আসবে কিনা চেক করুন

🔧 Alternative: Simple Email Setup

যদি EmailJS কমপ্লেক্স লাগে, তাহলে এই সিম্পল মেথড ব্যবহার করুন:
// sendEmailCode ফাংশনে এই লাইন রিপ্লেস করুন: window.open(`mailto:${email}?subject=${type} Code&body=Your verification code is: ${code}`);
এতে ইমেইল ক্লায়েন্ট খুলে যাবে এবং কোড দেখাবে।

❓ সমস্যা হলে?

- EmailJS Dashboard এ Error Logs চেক করুন
- Browser Console এ Error দেখুন
- Gmail এর ক্ষেত্রে "Less Secure Apps" enable করুন
- 2FA enabled থাকলে App Password ব্যবহার করুন
